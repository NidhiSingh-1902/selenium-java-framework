Key Implementation Notes
HTML5 Date Input
type="date" fields reject Selenium clear() — use JavascriptExecutor: set .value + dispatch change event so updateEndDate() auto-calculates end date
Readonly Fields
sprint_end_date has readonly=true (auto-calc from start + duration). fillForm() takes only (name, startDate) — no endDate param.
Parallel Test Isolation
Each method gets its own WebDriver via ThreadLocal. Sprint names carry System.currentTimeMillis() % 100_000 suffix to avoid data collisions.
Login IDs (Redmine 7)
id="username" · id="password" · id="login-submit" — standard Redmine, not the Lotus CRM theme (rf_username / rf_password)
Known Plugin Bug
board_configs index → HTTP 500 (ArgumentError in authorize). BoardConfigTest only covers /new, create, cancel — list page skipped.
